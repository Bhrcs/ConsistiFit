# Product Specification

## Core loop
Plan → train/recover → log → check in → earn RP/XP/Coins → progress → return tomorrow.

## Rank vs account level
- Account XP/level is permanent and never decreases.
- Consistency Rank measures plan adherence and can move over time.
- Coins never buy RP.

## Adaptive program rules
- One missed workout: preserve workout order and reflow dates.
- Two misses in a week: rebuild the remaining week around priority sessions.
- Repeated misses: suggest a lower weekly frequency.
- Repeated fatigue: preserve main lifts, reduce accessory volume, or prescribe recovery.
- Double progression: when all working sets reach the top of the rep range with controlled form, increase load slightly.
- Scheduled rest/recovery counts toward consistency. Extra unscheduled workouts grant 0 RP.

## Rank ladder
Iron → Bronze → Silver → Gold → Platinum → Diamond → Master → Grandmaster.
