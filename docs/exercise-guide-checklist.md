# Exercise guide acceptance checklist

- Active workout shows `How to perform + demo`.
- Every workout-order row has a guide arrow.
- Guide stays inside the workout flow and does not clear workout state.
- Guide contains overview, numbered steps, cues, common mistakes, substitution, and safety note.
- Three-phase demonstration is available for every generated exercise.
- Home, Gym Machines, Custom Equipment, Habit, Strength, and Cardio generated exercises receive a guide.
- Unknown future movements receive a safe fallback guide instead of failing.
- Web guide assets are cached by the PWA service worker.
- Flutter guide sheet is available from the current exercise and every workout-order row.
